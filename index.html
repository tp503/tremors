      How to play

      This is a solo-friendly table of the cooperative board game sketched in the design conversation. You control Val, Earl, Rhonda and Burt. If anyone dies, everyone loses.

      • Each character gets 2 actions (1 if Injured). Move, search, work objectives, divert, rescue, fight.
      • Noise is shared. Careful moves are quiet and slow. Guns, metal, and running feed the round total.
      • Location noise decays by 1 at the end of each round. Graboids hunt the loudest node in their sector.
      • Underground tokens climb a Hunt track. At Hunt 3 they surface — the model hits the board and cannot be ignored.
      • Sharing a surfaced Graboid’s node: Threatened → Grabbed → Dragged (game over). You have 3 Rescue tokens for the whole game.
      • Rounds 4, 7, 9, 11, 12 draw a Calamity. Severity is Quiet / Disturbed / Frenzy based on this round’s noise.
      • Finish every Essential objective and Evacuate, or still be alive with them done when round 12 ends.
